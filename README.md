# Skill City

La città delle skill di Claude Code di Riccardo: ogni skill è un mostriciattolo in pixel art,
i quartieri sono le aree (Finanza, Università, Sicurezza, Municipio) e gli edifici sono le
infrastrutture che le skill condividono. La pagina si apre come embed in Notion.

`dati.json` si aggiorna ogni sera e contiene solo numeri aggregati: chiamate per skill e per giorno,
come sono state chiamate, quali skill vengono usate di seguito. Niente orari, sessioni, cartelle o progetti.
